# Callback page font

`geist-latin.woff2` is the unmodified variable Geist Latin font bundled with
Next.js 16.3.4 (`next/dist/next-devtools/server/font/geist-latin.woff2`).
It is embedded in the CLI callback page so authorization needs no external font
requests. The CLI package includes this directory for both source and compiled
renderers.
